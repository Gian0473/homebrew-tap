# Sorteo POS · instaladores

Versión actual: **1.0.0**.

## macOS (Homebrew)

```bash
brew install --cask gian0473/tap/sorteo-pos
```

Para actualizar: `brew upgrade --cask sorteo-pos`. Requiere macOS 13 o superior.

## Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/Gian0473/homebrew-tap/main/instalar.ps1 | iex
```

Para actualizar, vuelve a ejecutar el mismo comando. Instala para el usuario actual, sin permisos de administrador.

## Activación

La primera vez, Sorteo POS muestra el código del equipo. Envíaselo a tu proveedor para recibir el token de activación y pégalo en la app. Internet solo se necesita para instalar: la app funciona sin conexión, y desinstalarla o actualizarla no borra la base de datos.
